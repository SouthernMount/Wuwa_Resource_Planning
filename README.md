# 鸣潮限定池资源规划工具

本项目是一个零依赖本地网页应用，用于计算鸣潮限定角色池与限定武器池的目标完成概率、硬保底资源缺口，并记录十连后的动态状态。
完成至少一次抽卡会话后，还可以估计下个卡池开放时的星声收入和可 100% 保底完成的最高目标。

本项目由 Codex 辅助完成。

## 使用

下载并解压项目后，双击：

```text
启动工具.bat
```

也可以直接双击 `index.html` 使用。项目不需要安装依赖。

## 可选本地服务器

如果本机已经安装 Node.js，也可以用本地服务器启动：

```powershell
cmd /c npm start
```

打开浏览器访问：

```text
http://localhost:4173
```

## 测试
