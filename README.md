# 鸣潮限定池资源规划工具

本项目是一个 Windows 优先的鸣潮限定池资源规划桌面工具，用于计算限定角色池与限定武器池的目标完成概率、硬保底资源缺口，并记录十连后的动态状态。
完成至少一次抽卡会话后，还可以估计下个卡池开放时的星声收入和可 100% 保底完成的最高目标。

本项目由 Codex 辅助完成。

## 使用

完整源码目录中可以双击：

```text
启动工具.bat
```

如果已安装依赖，会启动桌面版；如果缺少 Node.js 或 Electron 依赖，会自动打开网页备用模式并在窗口中显示原因。

自动捕捉和游戏浮窗仅在桌面版中可用。直接打开 `index.html` 时仍可使用基础规划、手动记录和未来估计，但无法捕捉游戏窗口。
浮窗进入鼠标穿透后无法直接点击自身按钮，这是系统层面的穿透行为；可按 `Ctrl+Shift+O`，或回到主窗口“自动捕捉监控”的“浮窗控制”中关闭“鼠标穿透”恢复交互。

## 开发启动

首次开发需要安装依赖：

```powershell
cmd /c npm install
```

启动桌面版：

```powershell
cmd /c npm start
```

## 可选本地服务器

如果只需要网页预览，也可以启动本地服务器：

```powershell
cmd /c npm run start:web
```

打开浏览器访问：

```text
http://localhost:4173
```

## 测试

```powershell
cmd /c npm test
```
