# 鸣潮限定池资源规划工具

本项目是一个零依赖本地网页应用，用于计算鸣潮限定角色池与限定武器池的目标完成概率、硬保底资源缺口，并记录十连后的动态状态。
完成至少一次抽卡会话后，还可以估计下个卡池开放时的星声收入和可 100% 保底完成的最高目标。

## 使用

```powershell
cmd /c npm start
```

打开浏览器访问：

```text
http://localhost:4173
```

也可以直接打开 `index.html` 使用。推荐使用本地服务器，浏览器兼容性更稳定。

## 测试

```powershell
cmd /c npm test
```

## 当前规则口径

- 角色池：80 抽硬保底，非大保底时五星为 50% UP / 50% 歪，歪后下一金必 UP。
- 武器池：80 抽硬保底，五星必为 UP 武器。
- 星声折算：160 星声 = 1 抽。
- 资源消耗：角色抽优先浮金波纹，武器抽优先铸潮波纹，不足时消耗星声。
- 软保底：默认开启社区估计曲线，界面标注为非官方公式；可关闭后只按基础概率与硬保底计算。
- 未来估计：按当前日期到下个卡池开放日期的日历天计算，每日 60 星声；拥有小月卡时每日 150 星声；每个周一额外 160 星声。
